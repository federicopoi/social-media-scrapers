# Credentials and private data

This repository contains source, documentation and synthetic tests only. Never commit or upload cookie files, passwords, access tokens, `.env` files, browser profile databases, Keychain material, personal configuration, downloaded media, archives, logs or private live-run records. Ignore rules reduce accidental additions but cannot detect every secret or remove one already committed.

Use your own authorized Facebook/Instagram session. Keep Netscape cookie exports outside the checkout with restricted file permissions. Read only the selected browser/profile and matching platform's cookies. Login and challenges must be completed manually by the user; no browser control or automated login is part of these tools. Do not ask anyone to paste cookies into chat.

If a session is exposed, revoke/sign out the affected platform sessions and replace the cookies. Deleting a file or Git commit does not invalidate stolen credentials. Review collected photos, captions, contact information and reviews before sharing outputs: public source material can still contain personal information.

Persisted GraphQL document IDs and public web-client operation identifiers in source are not personal login tokens or API keys. Test cookie values and credentials in rejection fixtures are synthetic.

Report issues with minimal reproductions and synthetic data. Never attach real cookie files, private source output or account credentials to a public issue. Use private vulnerability reporting in GitHub's Security tab when available for sensitive details.
